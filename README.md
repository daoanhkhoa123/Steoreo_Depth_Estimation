# Stereo Depth Estimation using SSD and Global Filter

Welcome to the **Stereo Depth Estimation using Sum of Squared Differences (SSD)** repository! This project focuses on depth estimation from stereo images using the SSD algorithm.

## Overview
Depth estimation is a key component of computer vision, where the goal is to estimate the depth of each pixel in an image. This repository implements a method using the Sum of Squared Differences (SSD) to compute disparity maps and infer depth.

## Features
- **Image Preprocessing**: Tools to prepare stereo image pairs.
- **Disparity Calculation**: Implementation of SSD to calculate disparity.
- **Depth Map Generation**: Converts disparity maps to depth maps.
- **Visualization**: Functions to visualize disparity and depth maps.
- **Evaluation**: Performance metrics to evaluate the accuracy of the depth estimation.
